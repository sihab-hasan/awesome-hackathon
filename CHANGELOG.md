# Changelog

## 1.0.0 — 2026-08-07

First public release of **Awesome Hackathon**.

- Established the canonical data-driven resource catalog and generated resource library.
- Consolidated architecture guidance, product specifications, implementation patterns, and reference builds into a unified blueprint system.
- Added the complete participant handbook covering discovery, team formation, problem selection, architecture, implementation, testing, security, deployment, demo, pitching, submission, and post-event continuation.
- Added organizer, mentor, judge, safety, submission, community, specialized-track, checklist, prompt, project-brief, and recovery operations.
- Added catalog schema 2.0 with audience, lifecycle-stage, platform, risk, source, status, and review metadata.
- Added deterministic catalog generation, offline search, freshness review, structured validation, repository tests, documentation navigation checks, and release evidence.
- Added cross-platform validation for Windows, macOS, and Linux, including deterministic LF writes, live-checkout Git metadata handling, and timezone-data-independent review-date validation.
- Added GitHub Actions for CI, documentation, links, security, dependency review, linting, spelling, freshness, Pages, and releases.
- Added repository governance, curation, quality, security, contribution, maintenance, support, and release policies.
- Organized non-essential root documentation under `docs/` while retaining standard GitHub entry, security, support, contribution, and release-history files at the repository root.
- Prepared the repository for its first public GitHub release as `v1.0.0`.
