# Judge Questions

## Problem

- Who experiences this problem, and what evidence informed the solution?
- What existing workflow or alternative does the project replace or improve?

## Product

- What is the smallest user outcome that works now?
- Which capability was deliberately excluded to protect the demo scope?

## Engineering

- Which component owns the authoritative data?
- What happens when the model, API, database, device, or network is unavailable?
- Which parts were created during the event and which existed beforehand?

## Trust

- What sensitive information enters the system?
- Which consequential actions require user confirmation?
- How was accessibility considered?

## Evidence and continuation

- What did the team test with users or representative data?
- What is the first validation step after the hackathon?
