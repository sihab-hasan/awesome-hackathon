# Judge Handbook

## Purpose

Judging should distinguish problem relevance, working outcomes, technical judgment, responsible design, and communication without rewarding polish alone or introducing unpublished criteria.

## Operating sequence

1. Read the rules, challenge definitions, rubric, tie-break order, accessibility guidance, and pre-existing-work policy.
2. Disclose conflicts and complete calibration before viewing live submissions.
3. Use the same timebox, core questions, and evidence standard for every eligible team.
4. Score independently before group deliberation.
5. Record concise evidence for unusually high or low scores.
6. Apply the published tie-break method and return constructive feedback.

## Fairness boundaries

Evaluate what is demonstrated and evidenced, not future promises. Do not penalize assistive technology, remote participation, unfamiliar accents, or narrow scope chosen for reliability. Do not reward undisclosed pre-existing work or sponsor affiliation. Separate sponsor-prize criteria from general-track scoring unless the event explicitly published a combined model.
