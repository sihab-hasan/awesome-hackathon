## Non-negotiable controls

Publish eligibility, intellectual-property terms, code of conduct, privacy, accessibility, judging, prizes, sponsor requirements, submission evidence, incident routes, and material restrictions before registration. Assign an owner and backup for every critical event function. Timestamp material changes and communicate them to every affected team.
