# Architecture Blueprints

Architecture blueprints describe a production-conscious end state while identifying the smallest vertical slice that can be demonstrated during a hackathon.

## Families

- Frontend, backend, and full-stack web applications
- Mobile and desktop applications
- AI assistants, agents, retrieval systems, and voice interfaces
- Data dashboards and machine-learning prototypes
- Realtime collaboration and live operations
- Hardware, sensors, and edge AI
- Browser extensions, command-line tools, games, and automation

## Decision sequence

1. Define the user journey and trust boundary.
2. Choose the simplest runtime the team already knows.
3. Identify authoritative data and external dependencies.
4. Design one deployable vertical slice.
5. Add observability, security, and a failure fallback.
6. Record deferred production concerns explicitly.
