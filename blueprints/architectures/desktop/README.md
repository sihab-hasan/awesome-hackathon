# Desktop Application Blueprints

Desktop applications are appropriate when the project needs local files, native operating-system integration, offline capability, or a persistent workstation experience.

- [Electron Blueprint](electron.md) — broad web ecosystem and mature native integration.
- [Tauri Blueprint](tauri.md) — smaller native shell with a web frontend and Rust-based commands.

Choose desktop delivery only when those capabilities materially support the core workflow; a web application is usually faster to distribute during a hackathon.
