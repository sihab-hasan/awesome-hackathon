# Product Specifications

These documents are product blueprints, not code generators. Each specification narrows a common product type into a demoable workflow with clear acceptance criteria.

## Included product types

Admin dashboards, AI chat, authentication, blogs, chat applications, content management, e-commerce, landing pages, portfolios, SaaS products, social networks, and task managers.

## Usage

Copy the relevant specification into the project repository. Remove optional features until one end-to-end user outcome works. Convert every retained capability into an observable acceptance test and a demo step.

## Exit criteria

A product specification is ready for implementation when the team agrees on the target user, core action, data model, scope exclusions, owner for each subsystem, deployment path, and fallback demo.
