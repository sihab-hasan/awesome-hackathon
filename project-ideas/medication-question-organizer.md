# Medication Question Organizer

## Problem

Help patients prepare structured questions for a clinician without giving medical advice.

## Data strategy

No diagnosis; use user-entered medication list and trusted references.

## Core demo

Enter medicines → identify discussion topics → export appointment summary.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
