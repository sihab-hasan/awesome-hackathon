# Food Rescue Coordinator

## Problem

Match surplus food with verified local recipients and pickup capacity.

## Data strategy

Sample donor, recipient, and logistics data.

## Core demo

Post surplus → eligibility match → scheduled pickup.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
