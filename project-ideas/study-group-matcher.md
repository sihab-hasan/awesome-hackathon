# Study Group Matcher

## Problem

Form small study groups based on course, availability, goals, and preferred working style.

## Data strategy

Synthetic student profiles.

## Core demo

Create profile → match → schedule first session.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
