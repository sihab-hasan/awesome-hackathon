# Small Business Queue Manager

## Problem

Let small service businesses manage walk-ins and send privacy-conscious status updates.

## Data strategy

Synthetic businesses and customers.

## Core demo

Join queue → staff updates status → customer receives estimate.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
