# Civic Form Assistant

## Problem

Explain public forms in plain language and create a completion checklist.

## Data strategy

Public form instructions; no legal advice.

## Core demo

Choose form → answer eligibility questions → receive checklist.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
