# Disaster Resource Board

## Problem

Aggregate verified shelters, supplies, and service updates with freshness indicators.

## Data strategy

Public emergency feeds or seeded incident data.

## Core demo

Search location → inspect verified resources → report stale information.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
