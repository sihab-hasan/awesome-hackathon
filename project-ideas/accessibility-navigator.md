# Accessibility Navigator

## Problem

Help users identify and plan around accessibility barriers in a venue or workflow.

## Data strategy

Map or structured venue data; user-submitted reports.

## Core demo

Crowdsourced barrier report → accessible route or preparation checklist.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
