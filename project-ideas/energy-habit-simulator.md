# Energy Habit Simulator

## Problem

Show how household choices could affect estimated energy use and cost.

## Data strategy

Published conversion factors and clearly labeled assumptions.

## Core demo

Enter habits → compare scenarios → export action plan.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
