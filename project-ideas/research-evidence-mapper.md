# Research Evidence Mapper

## Problem

Organize papers by claim, evidence type, population, and contradiction.

## Data strategy

Open paper metadata and user-provided notes.

## Core demo

Import papers → extract structured claims → compare evidence.

## Guardrails

- Identify the real user and verify assumptions.
- Use synthetic data when personal data is unnecessary.
- Label estimates and generated content.
- Keep a deterministic demo path.

## Stretch direction

Add integrations only after the core workflow is reliable.
