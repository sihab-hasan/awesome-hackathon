# Testing Checklist

Use this list as a release gate. Record unresolved items as explicit risks rather than silently skipping them.

- [ ] Core user journey tested from a clean session.
- [ ] Invalid and empty input tested.
- [ ] Authentication and authorization boundaries tested.
- [ ] Slow, unavailable, and rate-limited dependencies tested.
- [ ] Mobile and keyboard navigation checked.
- [ ] Representative AI or data cases evaluated.
- [ ] Deployment smoke test completed.
- [ ] Recorded fallback verified.

## Sign-off

Record the owner, timestamp, tested artifact, and any accepted exception.
