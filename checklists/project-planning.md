# Project Planning Checklist

Use this list as a release gate. Record unresolved items as explicit risks rather than silently skipping them.

- [ ] Target user and problem evidence written.
- [ ] One measurable user outcome selected.
- [ ] Core flow represented as a vertical slice.
- [ ] Out-of-scope list agreed.
- [ ] External dependencies and fallback data identified.
- [ ] Data classification and consent requirements reviewed.
- [ ] Owners and checkpoints assigned.
- [ ] Demo narrative drafted before implementation.

## Sign-off

Record the owner, timestamp, tested artifact, and any accepted exception.
