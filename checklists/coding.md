# Coding Checklist

Use this list as a release gate. Record unresolved items as explicit risks rather than silently skipping them.

- [ ] Main branch protected from uncontrolled changes.
- [ ] Small integration increments used.
- [ ] Environment variables documented.
- [ ] Input validation and error handling included.
- [ ] External calls use timeouts.
- [ ] Seed data and local fallback maintained.
- [ ] Automated checks run before merge.
- [ ] Working demo build tagged at every major checkpoint.

## Sign-off

Record the owner, timestamp, tested artifact, and any accepted exception.
