# Security Checklist

Use this list as a release gate. Record unresolved items as explicit risks rather than silently skipping them.

- [ ] Secret scan clean.
- [ ] Least-privilege credentials used.
- [ ] Protected actions authorized server-side.
- [ ] Sensitive logs and screenshots removed.
- [ ] Uploads constrained by type and size.
- [ ] Consequential actions require confirmation.
- [ ] Dependencies and containers scanned.
- [ ] Temporary credentials scheduled for rotation.

## Sign-off

Record the owner, timestamp, tested artifact, and any accepted exception.
