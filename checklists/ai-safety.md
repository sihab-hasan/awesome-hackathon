# Ai Safety Checklist

Use this list as a release gate. Record unresolved items as explicit risks rather than silently skipping them.

- [ ] Model purpose and prohibited uses documented.
- [ ] Representative prompts and failure cases evaluated.
- [ ] Prompt injection and untrusted content considered.
- [ ] Sensitive data excluded or protected.
- [ ] Model output visibly identified where needed.
- [ ] Human confirmation protects consequential actions.
- [ ] Non-AI fallback or safe failure mode available.
- [ ] Limitations and provider dependencies disclosed.

## Sign-off

Record the owner, timestamp, tested artifact, and any accepted exception.
