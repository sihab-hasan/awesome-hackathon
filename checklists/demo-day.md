# Demo Day Checklist

Use this list as a release gate. Record unresolved items as explicit risks rather than silently skipping them.

- [ ] Stable release frozen.
- [ ] Seeded accounts and data prepared.
- [ ] Browser tabs and device permissions reset.
- [ ] Network-independent fallback available.
- [ ] Presenter and operator roles assigned.
- [ ] Timer and transition cues rehearsed.
- [ ] Submission links verified.
- [ ] Post-demo question owner identified.

## Sign-off

Record the owner, timestamp, tested artifact, and any accepted exception.
