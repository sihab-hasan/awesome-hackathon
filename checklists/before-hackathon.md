# Before Hackathon Checklist

Use this list as a release gate. Record unresolved items as explicit risks rather than silently skipping them.

- [ ] Event rules, dates, timezone, eligibility, and judging criteria saved.
- [ ] Team roles and communication channel agreed.
- [ ] Accounts and development environments tested.
- [ ] Credits and provider quotas verified.
- [ ] Problem shortlist prepared.
- [ ] Accessibility or dietary accommodations requested.
- [ ] Repository and secret-management plan ready.
- [ ] Travel, venue, power, device, and network needs confirmed.

## Sign-off

Record the owner, timestamp, tested artifact, and any accepted exception.
