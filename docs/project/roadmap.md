# Roadmap

## Maintenance outcomes

- Preserve deterministic catalog generation and schema compatibility.
- Keep active resources within the editorial review window.
- Expand regional, multilingual, low-bandwidth, and accessibility coverage using verifiable sources.
- Improve organizer safety, hybrid-event, judging, and post-event operations.
- Add reference builds only when they demonstrate distinct architecture and validation decisions.
- Strengthen link health, release provenance, dependency review, and documentation build evidence.
- Develop a community-reviewed showcase without turning recognition into endorsement.

## Success measures

Success is measured through useful coverage, low duplication, current review evidence, resolved links, reproducible generated views, actionable guidance, contributor diversity, and safe event operations. File count and resource count are not standalone goals.
