# Frequently Asked Questions

## Is every listed tool free?

No. The catalog records a high-level cost model, but pricing and event credits can change. Verify official terms.

## Is this a code starter repository?

It is primarily a resource catalog and field guide. Templates are architecture blueprints rather than unreviewed generated applications.

## Can a project use AI-generated code?

Follow event rules, review all generated output, test it, and disclose assistance when required.

## Are listed resources endorsed?

No. Inclusion means the resource met the editorial criteria at review time.
