## Current owner

- [`sihab-hasan`](https://github.com/sihab-hasan) — repository administration, releases, governance, and security escalation

## Maintainer model

Additional maintainers and category reviewers are appointed through the governance process. Access follows least privilege and is reviewed periodically.

Maintainer responsibilities include evidence-based curation, affiliation disclosure, respectful review, scheduled freshness work, release verification, workflow security, and private handling of security or conduct reports.

See [Governance](governance.md) and the [Maintainer Playbook](playbook.md).
