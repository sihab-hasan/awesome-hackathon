# Community Events

This page defines how community events may be referenced without becoming an unmaintained event calendar.

## Inclusion

Events should have a public organizer, clear dates, rules, eligibility, code of conduct, and canonical registration page. Recurring event platforms belong in the resource catalog; individual time-sensitive events should use the event issue template.

## Expiration

Past events are removed from the active list after results and project links are captured. The repository does not guarantee event legitimacy, visa eligibility, travel support, prizes, or organizer conduct.

## Safety

Report suspicious registration, payment requests, impersonation, or credential collection through the security or moderation channels before linking the event.
