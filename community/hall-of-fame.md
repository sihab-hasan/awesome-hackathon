# Hall of Fame Policy

This repository does not maintain an unverified winners list. A project may be featured only when an organizer-published result or canonical event page confirms the recognition.

## Required evidence

Record the event, year, category, project, team attribution, official result URL, repository or demo, and license when available.

## Neutrality

Inclusion documents a verifiable outcome; it is not a claim that the project is safe, maintained, production ready, or superior outside the event context.
