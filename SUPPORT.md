# Support

## Repository usage

Use GitHub Discussions for questions about navigation, catalog search, playbooks, blueprints, or contribution workflow. Include the goal, event duration, team constraints, and page already consulted.

## Corrections

- Broken, outdated, or missing resource: resource request issue form
- Documentation clarity or coverage: documentation issue form
- Validation, generation, or workflow defect: repository problem issue form
- Project showcase or event proposal: the relevant structured issue form

## Private reports

- Security concern: GitHub private vulnerability report
- Conduct, harassment, safeguarding, or personal-data concern: private maintainer contact

Do not include credentials, private participant data, medical information, or sensitive incident evidence in public support channels.

## Boundary

Maintainers cannot provide account recovery, billing, quota, legal, medical, security-incident, or product support for third-party resources. Contact the resource owner through its official support channel.
