# Vector Databases Resources

Curated resources for hackathon teams. Last catalog generation: **2026-08-07**.

| Resource | Best for | Cost | Source | Risk |
| --- | --- | --- | --- | --- |
| [Pinecone](https://docs.pinecone.io/) | Managed vector retrieval | Free tier and paid | Official | Low |
| [Qdrant](https://qdrant.tech/documentation/) | Vector search and RAG | Open source and cloud | Official | Low |
| [Weaviate](https://docs.weaviate.io/) | Semantic and hybrid retrieval | Open source and cloud | Official | Low |

## Selection guidance

Prefer the smallest tool the team already understands. Confirm current pricing, quotas, regional availability, event eligibility, and data-handling terms before committing the demo to a provider.
