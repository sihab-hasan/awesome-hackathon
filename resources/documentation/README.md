# Documentation Resources

Curated resources for hackathon teams. Last catalog generation: **2026-08-07**.

| Resource | Best for | Cost | Source | Risk |
| --- | --- | --- | --- | --- |
| [Docusaurus](https://docusaurus.io/docs) | Feature-rich project documentation and public handbooks | Open source | Official | Low |
| [MkDocs](https://www.mkdocs.org/) | Simple documentation sites built from Markdown | Open source | Official | Low |
| [Storybook](https://storybook.js.org/docs) | Documenting and reviewing reusable interface components | Open source | Official | Low |
| [VitePress](https://vitepress.dev/) | Fast documentation sites for JavaScript projects | Open source | Official | Low |

## Selection guidance

Prefer the smallest tool the team already understands. Confirm current pricing, quotas, regional availability, event eligibility, and data-handling terms before committing the demo to a provider.
