# Maps Resources

Curated resources for hackathon teams. Last catalog generation: **2026-08-07**.

| Resource | Best for | Cost | Source | Risk |
| --- | --- | --- | --- | --- |
| [Google Maps Platform](https://developers.google.com/maps/documentation) | Location and places applications | Usage based with credits | Official | Low |
| [Leaflet](https://leafletjs.com/reference.html) | Simple interactive maps | Open source | Official | Low |
| [Mapbox Developers](https://www.mapbox.com/developers) | Polished geospatial products | Free tier and paid | Official | Low |
| [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/handbook/) | Custom vector maps | Open source | Official | Low |
| [OpenStreetMap](https://www.openstreetmap.org/) | Open geographic data | Open data | Official | Low |

## Selection guidance

Prefer the smallest tool the team already understands. Confirm current pricing, quotas, regional availability, event eligibility, and data-handling terms before committing the demo to a provider.
