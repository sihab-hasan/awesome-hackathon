# Data Visualization Resources

Curated resources for hackathon teams. Last catalog generation: **2026-08-07**.

| Resource | Best for | Cost | Source | Risk |
| --- | --- | --- | --- | --- |
| [Apache ECharts](https://echarts.apache.org/en/option.html) | Dashboards and complex charts | Open source | Official | Low |
| [D3.js](https://d3js.org/getting-started) | Custom interactive charts | Open source | Official | Low |
| [Plotly](https://plotly.com/javascript/) | Scientific and analytical charts | Open source and paid | Official | Low |

## Selection guidance

Prefer the smallest tool the team already understands. Confirm current pricing, quotas, regional availability, event eligibility, and data-handling terms before committing the demo to a provider.
