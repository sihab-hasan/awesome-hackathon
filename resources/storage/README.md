# Storage Resources

Curated resources for hackathon teams. Last catalog generation: **2026-08-07**.

| Resource | Best for | Cost | Source | Risk |
| --- | --- | --- | --- | --- |
| [Amazon S3](https://docs.aws.amazon.com/s3/) | Cloud-native object storage and event-driven file workflows | Usage based | Official | Medium |
| [Cloudinary](https://cloudinary.com/documentation) | Image and video workflows | Free tier and paid | Official | Medium |
| [Supabase Storage](https://supabase.com/docs/guides/storage) | File storage in applications already using Supabase | Free tier and paid plans | Official | Medium |
| [UploadThing](https://docs.uploadthing.com/) | Fast web file uploads | Free tier and paid | Official | Medium |

## Selection guidance

Prefer the smallest tool the team already understands. Confirm current pricing, quotas, regional availability, event eligibility, and data-handling terms before committing the demo to a provider.
