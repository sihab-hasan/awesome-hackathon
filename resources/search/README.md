# Search Resources

Curated resources for hackathon teams. Last catalog generation: **2026-08-07**.

| Resource | Best for | Cost | Source | Risk |
| --- | --- | --- | --- | --- |
| [Algolia](https://www.algolia.com/doc/) | Fast polished search | Free tier and paid | Official | Low |
| [Meilisearch](https://www.meilisearch.com/docs) | Self-hosted application search | Open source and cloud | Official | Low |
| [Typesense](https://typesense.org/handbook/) | Instant search experiences | Open source and cloud | Official | Low |

## Selection guidance

Prefer the smallest tool the team already understands. Confirm current pricing, quotas, regional availability, event eligibility, and data-handling terms before committing the demo to a provider.
