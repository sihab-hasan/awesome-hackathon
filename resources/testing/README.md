# Testing Resources

Curated resources for hackathon teams. Last catalog generation: **2026-08-07**.

| Resource | Best for | Cost | Source | Risk |
| --- | --- | --- | --- | --- |
| [Cypress](https://docs.cypress.io/) | Interactive browser tests | Open source and paid | Official | Low |
| [k6](https://grafana.com/handbook/k6/latest/) | API load tests | Open source and cloud | Official | Low |
| [Playwright](https://playwright.dev/handbook/intro) | Critical user-flow tests | Open source | Official | Low |
| [pytest](https://docs.pytest.org/) | Python unit and integration tests | Open source | Official | Low |
| [Vitest](https://vitest.dev/guide/) | Frontend and Node unit tests | Open source | Official | Low |

## Selection guidance

Prefer the smallest tool the team already understands. Confirm current pricing, quotas, regional availability, event eligibility, and data-handling terms before committing the demo to a provider.
