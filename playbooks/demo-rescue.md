# Demo Rescue Playbook

## Stabilize

Stop feature work. Identify the shortest working user journey.

## Isolate

Disable unreliable optional integrations and use deterministic demo data.

## Record

Capture a clean backup video and screenshots.

## Rehearse

Write exact narration and recovery transitions.

## Disclose

State limitations honestly; never represent mock behavior as live.

## Exit condition

The core claim is demonstrable, limitations are explicit, and the team has a tested fallback.
