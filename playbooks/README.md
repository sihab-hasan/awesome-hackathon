# Execution Playbooks

Playbooks are operational sequences for common time constraints and failure scenarios. Each playbook defines triggers, roles, decisions, checkpoints, fallbacks, and exit criteria.

## Usage

Assign one incident owner, preserve the smallest working path, communicate scope changes, and stop adding features until the exit criteria are met.
