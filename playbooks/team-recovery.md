# Team Recovery Playbook

## Trigger

Use when responsibilities are unclear, integration repeatedly fails, scope disputes block progress, or a critical member becomes unavailable.

## Fifteen-minute reset

1. Restate the target user and single demo outcome.
2. List what works now.
3. Remove optional features.
4. Assign one owner for product, integration, deployment, and presentation.
5. Set the next checkpoint and stop parallel changes to shared files.

## Integration rule

Work from one protected main branch, small pull requests, and an agreed integration owner. New branches must prove they support the core demo before merging.

## Exit criteria

Every retained task has an owner, the integration sequence is clear, the next working build has a deadline, and the team agrees on the fallback demo.
