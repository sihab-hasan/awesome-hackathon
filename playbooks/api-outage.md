# External API Outage Playbook

## Detect

Confirm timeout, quota, credentials, and provider status.

## Bound

Apply a strict timeout and prevent retry storms.

## Fallback

Use cached, seeded, or clearly labeled sample responses.

## Communicate

Expose degraded state in the UI and demo narrative.

## Recover

Restore service without losing user input or duplicating actions.

## Exit condition

The core claim is demonstrable, limitations are explicit, and the team has a tested fallback.
