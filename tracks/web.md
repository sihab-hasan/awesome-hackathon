# Web Track

## Outcome

A deployable, accessible web workflow with authentication and data ownership only when required.

## Delivery principles

- Use semantic HTML.
- Test mobile widths.
- Protect server actions.
- Seed deterministic demo data.
- Monitor runtime errors.

## Required evidence

Show the user problem, one end-to-end workflow, architecture boundary, test evidence, failure fallback, and the next validation step.

## Common failure

Teams lose time by adding technologies before proving the core interaction. Freeze the stack once the first vertical slice works.
