# Data Track

## Outcome

A reproducible pipeline from source to transformation, quality check, analysis, and visual evidence.

## Delivery principles

- Document source and license.
- Preserve raw data.
- Validate schema and missing values.
- Separate analysis from presentation.
- State uncertainty.

## Required evidence

Show the user problem, one end-to-end workflow, architecture boundary, test evidence, failure fallback, and the next validation step.

## Common failure

Teams lose time by adding technologies before proving the core interaction. Freeze the stack once the first vertical slice works.
