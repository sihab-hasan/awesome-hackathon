# Mobile Track

## Outcome

A focused mobile journey that works on at least one real device and handles offline or degraded connectivity.

## Delivery principles

- Test permissions.
- Handle slow networks.
- Use accessible controls.
- Record a device demo.
- Avoid unnecessary native modules.

## Required evidence

Show the user problem, one end-to-end workflow, architecture boundary, test evidence, failure fallback, and the next validation step.

## Common failure

Teams lose time by adding technologies before proving the core interaction. Freeze the stack once the first vertical slice works.
