# AI Track

## Outcome

A bounded AI-assisted workflow with deterministic validation and a non-AI fallback.

## Delivery principles

- Define where the model may be wrong.
- Separate retrieval from generation.
- Log prompts without sensitive data.
- Evaluate representative cases.
- Require confirmation for consequential actions.

## Required evidence

Show the user problem, one end-to-end workflow, architecture boundary, test evidence, failure fallback, and the next validation step.

## Common failure

Teams lose time by adding technologies before proving the core interaction. Freeze the stack once the first vertical slice works.
