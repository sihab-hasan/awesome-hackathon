# Hardware Track

## Outcome

A safe, observable sensor or actuator loop with simulation and recorded fallback.

## Delivery principles

- Document electrical limits.
- Use safe enclosures.
- Provide simulated data.
- Calibrate sensors.
- Treat remote actions as consequential.

## Required evidence

Show the user problem, one end-to-end workflow, architecture boundary, test evidence, failure fallback, and the next validation step.

## Common failure

Teams lose time by adding technologies before proving the core interaction. Freeze the stack once the first vertical slice works.
