# Beginner Track

## Outcome

A narrow web or mobile workflow with one data source and one deployable outcome.

## Delivery principles

- Use familiar tools.
- Prefer managed services.
- Avoid multi-agent or microservice complexity.
- Ship a seeded demo early.

## Required evidence

Show the user problem, one end-to-end workflow, architecture boundary, test evidence, failure fallback, and the next validation step.

## Common failure

Teams lose time by adding technologies before proving the core interaction. Freeze the stack once the first vertical slice works.
