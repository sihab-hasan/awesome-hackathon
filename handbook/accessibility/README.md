# Accessibility

Accessibility improves the demo for judges and makes the product usable by more people.

## Minimum baseline

- Use semantic headings, landmarks, labels, buttons, and links.
- Ensure every input has an associated label and useful error text.
- Support keyboard navigation with a visible focus indicator.
- Do not use color as the only way to communicate meaning.
- Maintain readable contrast and responsive text sizing.
- Provide text alternatives for meaningful images and captions or transcripts for important media.
- Respect reduced-motion preferences.
- Test the primary workflow with a keyboard and an automated accessibility checker.

## Demo evidence

Show one accessibility decision that materially improves the core workflow. Do not claim formal conformance unless the product has received an appropriate audit.
