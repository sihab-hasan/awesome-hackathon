# Privacy and Data Protection

## Data minimization

Collect only the data needed for the demonstrated workflow. Prefer synthetic or anonymized data. Do not copy production, medical, financial, educational, location, biometric, or identity data into an unreviewed prototype.

## User expectations

Explain what is collected, why it is used, where it is sent, how long it is retained, and how it can be deleted. Obtain meaningful consent when the workflow depends on optional data or external sharing.

## Engineering baseline

- Keep secrets and personal data out of logs and analytics.
- Restrict access by role and environment.
- Encrypt network traffic.
- Provide a reset or deletion path for demo accounts.
- Review every third-party API and model provider before sending user content.

Event submission does not substitute for a privacy or regulatory assessment.
