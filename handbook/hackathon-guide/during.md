# During the Hackathon

## Operating rhythm

- Reconfirm scope at each milestone.
- Integrate continuously; avoid long-lived branches.
- Keep the deployed demo close to main.
- Record decisions and API credentials in approved secret stores, never chat history or source files.
- Test the core journey after every major integration.
- Start the submission and pitch before implementation ends.

When blocked for more than 30 minutes, simplify, stub safely, switch to seeded data, or ask a mentor.
