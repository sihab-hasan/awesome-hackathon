# Before the Hackathon

- Verify eligibility, team size, intellectual-property terms, allowed prior work, submission deadline, and judging criteria.
- Confirm accounts, student benefits, API access, hardware, charging, connectivity, and backup internet.
- Practice Git workflow and deployment once.
- Prepare reusable personal tooling, not event-specific product code unless rules allow it.
- Decide how the team will attribute third-party assets and open-source dependencies.
