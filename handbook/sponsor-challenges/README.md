# Sponsor Challenges

Sponsor tools should support the problem rather than define it.

## Selection

Read the exact judging criteria, required product usage, eligible APIs, credits, submission fields, branding rules, and prize conditions. Confirm that the integration can be demonstrated within event time and account limits.

## Implementation

Create one meaningful integration that affects the core workflow. Keep credentials server-side, use test environments, and provide fallback behavior when the sponsor service is unavailable.

## Pitch

Explain why the sponsor capability is necessary, what you built with it, and how it improves the user outcome. Avoid a superficial API call added only to qualify for a prize.
