# Open-Source Readiness

## Before publishing

- Remove secrets, personal data, generated credentials, internal URLs, and proprietary materials.
- Choose a license deliberately.
- Document setup, architecture, supported environments, limitations, and attribution.
- Add contribution, conduct, support, and security guidance proportional to the project's expected use.
- Create beginner-friendly issues only when maintainers can review contributions.

Do not label a repository open source merely because the source is visible; the license determines reuse rights.
