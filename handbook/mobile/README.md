# Mobile Projects

## Hackathon defaults

Prefer a cross-platform framework already known by the team. Minimize native modules, permissions, background processing, and store-review dependencies unless they are central to the project.

## Quality gates

- Test on at least one physical device and one small-screen layout.
- Handle offline, slow-network, denied-permission, and expired-session states.
- Avoid storing sensitive tokens in ordinary local storage.
- Explain platform limitations and whether the submitted build is signed, development-only, or distributed through a test channel.

Prepare a screen recording because wireless networks, device mirroring, and build services can fail during judging.
