# Deployment

Deploy in the first quarter of the event, not the final hour.

## Minimum production-like setup

- Environment variables documented and kept out of source control
- Repeatable build command
- Health endpoint or visible readiness signal
- Seed or migration command
- HTTPS
- Logs accessible to the team
- Rollback path
- Stable demo URL

Test from a private browser window and a device not used for development.
