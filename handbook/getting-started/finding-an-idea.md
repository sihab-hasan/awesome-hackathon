# Finding a Strong Idea

Start with a specific user struggling to complete a specific task. Avoid beginning with a technology and searching for a justification.

## Problem filter

Score each idea from 1–5:

- Problem is real and easy to explain.
- User can be identified and reached.
- Outcome can be demonstrated.
- A meaningful workflow fits the event duration.
- Required data and APIs are available.
- Team has enough technical familiarity.
- Idea aligns with judging criteria without forcing sponsor tools.

Discard ideas with unavailable data, unclear users, or a demo that depends entirely on uncontrolled external systems.
