# Getting Started

A hackathon is a time-boxed product experiment. Teams turn a problem into a working demonstration and communicate why it matters.

## Recommended sequence

1. Read the rules and judging criteria.
2. Form a small team with complementary ownership.
3. Select a problem with an observable user and outcome.
4. Define one core workflow.
5. Choose familiar tools.
6. Deploy early and rehearse repeatedly.

Continue with [choosing a team](choosing-a-team.md), [finding an idea](finding-an-idea.md), [choosing a stack](tech-stack.md), and [building a first project](first-project.md).
