# Your First Hackathon Project

Build one vertical slice before adding breadth.

## First three hours

- Read rules and submission fields.
- Write the one-sentence problem statement.
- Sketch the happy-path journey.
- Create repository, issue board, and deployment target.
- Seed realistic demo data.
- Deploy a placeholder immediately.

## First working milestone

A user can enter the system, complete the primary action, and see a useful result. It may be visually rough, but it must work end to end.

After the slice works, improve reliability, design, evidence, and storytelling—in that order.
