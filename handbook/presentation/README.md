# Presentation and Demo

Use a scripted, rehearsed journey with seeded data.

- Open with the user and problem.
- Show the product by the first third of the presentation.
- Demonstrate one coherent workflow.
- Narrate outcomes, not clicks.
- Keep backup screenshots and a short recording.
- Close with impact, technical insight, limitations, and next steps.

See the [demo-day checklist](../checklists/demo-day.md).
