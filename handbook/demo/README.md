# Demo Engineering

## Narrative

Use a simple sequence: user problem, current friction, product workflow, visible result, evidence, architecture, and next step. Every screen should support that narrative.

## Reliability

- Seed realistic non-sensitive data.
- Use a dedicated demo account.
- Remove unnecessary navigation and setup steps.
- Rehearse from a clean browser or device.
- Prepare a recording, screenshots, and a local fallback.
- Freeze risky changes before the final rehearsal.

## Timing

Leave time for judge questions. A shorter working demonstration is stronger than a rushed tour of unfinished features.
