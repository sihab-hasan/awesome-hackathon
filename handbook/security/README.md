# Security Baseline

- Never commit credentials, tokens, private keys, or real personal data.
- Validate input and encode output.
- Use least-privilege service credentials.
- Require confirmation for payments, messages, deletion, and other consequential actions.
- Restrict uploads by size and type; scan when risk warrants it.
- Protect administrative routes.
- Avoid logging secrets and sensitive content.
- Rotate temporary credentials after the event.

Use [checklists/security.md](../checklists/security.md) before submission.
